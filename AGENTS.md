# Правила проекта Gaido UA

## Стек и архитектура проекта
- **Проект:** Платформа каталогов для украинцев за границей (`gaido-ua.com`), объединяющая 3 основных направления:
  1. Гиды и авторские экскурсии.
  2. Международные перевозки (маршрутки, трансферы, попутки).
  3. Услуги специалистов (врачи, мастера, юристы и др.).
- **Бэкенд:** Go (API, работа с БД, загрузка медиа, авторизация).
- **Фронтенд:** Next.js + React + TypeScript.
- **Язык интерфейса:** Украинский (все тексты, плейсхолдеры, ошибки и подсказки для пользователей писать строго на украинском языке).

## Игнорируемые директории и файлы (НЕ ЧИТАТЬ И НЕ СКАНИРОВАТЬ)
При поиске, анализе и чтении кодовой базы **строго запрещено** заходить в следующие директории и читать указанные файлы (даже если они присутствуют в репозитории):
- `node_modules/`
- `**/.next/`
- `**/dist/`
- `backend/storage/` (загруженные медиафайлы и статика)
- `.local/`
- `**/*.tsbuildinfo`, `coverage/`, `*.out`

Для проверки установленных пакетов читай исключительно `package.json` и `backend/go.mod`.

## Правила работы с кодом и Git
1. **Не делай `git commit` самостоятельно** — все изменения проверяются разработчиком вручную через PhpStorm.
2. Перед внесением правок в БД или API сначала покажи план изменений и список затрагиваемых файлов.
3. **Соблюдай обратную совместимость между разделами:** при изменении профилей, авторизации, никнеймов или статистики учитывай, что пользовательская база и часть сущностей могут быть общими для гидов, перевозчиков и специалистов услуг.
4. После правки кода проверяй сборку (Go build / TypeScript check), чтобы не оставлять битых импортов.
